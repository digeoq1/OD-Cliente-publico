# OscuroDiamante 99B+ — cliente público

Descarga la versión vigente desde **Releases**. Extrae el ZIP completo en una carpeta nueva y ejecuta `Launcher.exe` (o `Jugar.cmd`). El launcher revisa el feed firmado por RSA sobre HTTPS y abre el cliente. `Launcher.exe` y `Updater.exe` quedan en la raíz del cliente.

- Cliente MU Online 99B+, versión 0.99.28.
- ConnectServer público: `186.182.184.21:44415/TCP`; GameServer anunciado por ConnectServer.
- El manifiesto firmado y los archivos de actualización se sirven desde este repositorio. La clave privada de firma no se publica; el launcher incorpora la clave pública fijada.
- El acceso externo depende de que el servidor y el encaminamiento de red estén disponibles.

No mezcles esta instalación con otros clientes MU. La comprobación de conexión y actualización en una PC externa debe hacerse manualmente con el servidor disponible.
