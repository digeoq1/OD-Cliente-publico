# OscuroDiamante 99B+ — Cliente Beta

Descarga inicial del cliente beta de OscuroDiamante 99B+.

## Instalación

1. Descarga `OscuroDiamante-99B-Beta-v1.0.0-beta1.zip` desde la sección Releases.
2. Extrae todo el ZIP en una carpeta propia, sin mezclarlo con otra instalación de MU.
3. Ejecuta `Launcher.exe`. El launcher comprueba el manifiesto firmado por HTTPS y abre el actualizador antes de iniciar el cliente.
4. En el launcher, pulsa **Play/Connect** para abrir `main.exe`.

El feed de actualización se sirve por HTTPS desde este repositorio. El manifiesto lleva firma RSA verificada por la clave pública incluida en el launcher; la clave privada no se publica.

## Compatibilidad

Cliente clásico MU Online 99B+ para Windows. El servidor debe estar disponible para poder completar la conexión de juego.

## Beta

Esta es una distribución beta. Conserva una copia del ZIP instalado si necesitas volver a una versión anterior. Las notas de cada actualización se publicarán en Releases.
